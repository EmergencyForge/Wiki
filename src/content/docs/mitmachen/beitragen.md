## Doku verbessern

Am schnellsten hilfst du, indem du diese Doku korrigierst oder ergänzt. Unter jeder Seite steht der Link **Seite bearbeiten**. Er öffnet die Markdown-Datei auf GitHub, dort schlägst du deine Änderung als Pull Request vor.

Wie Seiten aufgebaut sind und wie du die Doku lokal startest, steht unter [Doku bearbeiten](/mitmachen/doku-bearbeiten/).

## Fehler melden

Melde Fehler dort, wo sie entstehen:

| Was ist kaputt? | Wohin damit? |
| --- | --- |
| ignis | [EmergencyForge/ignis](https://github.com/EmergencyForge/ignis/issues) |
| ignisTab | [EmergencyForge/ignisTab](https://github.com/EmergencyForge/ignisTab/issues) |
| Diese Doku | [EmergencyForge/Wiki](https://github.com/EmergencyForge/Wiki/issues) |

Schreib dazu, welche Version du nutzt, was du gemacht hast und was passiert ist. Zeigt ignis eine Fehler-ID an, gib sie mit an.

## Code beitragen

1. Forke das Repository.
2. Leg einen Branch für deine Änderung an.
3. Öffne einen Pull Request gegen `main`.

Eine Änderung pro Pull Request macht das Prüfen leichter.
