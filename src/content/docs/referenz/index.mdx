## Schreibweise

| Angabe | Bedeutung |
|---|---|
| <span class="ef-badge client">Client</span> | läuft im Client-Script |
| <span class="ef-badge server">Server</span> | läuft im Server-Script |
| <span class="ef-badge shared">Shared</span> | gibt es auf beiden Seiten mit gleichem Aufruf |
| <span class="ef-badge event">Event</span> | ein Event statt eines Exports. Der Aufruf zeigt, ob du zuhörst (`AddEventHandler`) oder es auslöst (`TriggerClientEvent`, `TriggerServerEvent`). |
| `optional` | der Parameter darf fehlen, dann gilt der genannte Standard |
